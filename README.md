# 客户基金资产配置健诊报告 Skill

根据客户基金持仓、可选产品池和调仓边界，生成固定内容编排与版式的中文 Word 健诊报告。

当前版本：**v1.1.0**

## 下载

- [下载完整分享包 v1.1.0](./客户基金资产配置健诊报告Skill_分享包_v1.1.0.zip)

分享包内含 Codex、WorkBuddy、豆包/扣子三个版本，以及脱敏 Word 模板、生成脚本、输入示例、安装说明和使用说明。

## 本版功能

- 按报告日动态生成“上月市场复盘 + 本月观察与展望”。
- 指数表展示最近完整月及最近两个完整月累计表现。
- 基于最新已披露季报的大类资产穿透和前十大重仓股行业归因。
- 持仓明细、主要指数和操作建议按红涨绿跌显示。
- “1. 存量持仓”“2. 调入产品/新增资金”“3. 操作节奏”采用相同组内小标题格式。
- 包含完整风险提示和可编辑 DOCX 输出。

## Codex 安装

1. 下载并解压总分享包。
2. 找到 Codex 安装包并解压，将 client-fund-health-report 文件夹放入 ~/.codex/skills/。
3. 重新打开 Codex，输入：使用 $client-fund-health-report，根据我上传的持仓、可选产品和调整要求生成 Word 健诊报告。

## 使用时需要提供

1. 持仓数据截止日、基金代码、全称、份额类别、市值、成本及收益。
2. 可转换或新建仓产品的名称、代码、销售档期、开放状态、风险等级及持有期。
3. 是否允许赎回、转换、加仓和新建仓；新增资金、最多调出/调入数量及必须保留或禁止新增的产品。
4. 如有：风险等级、预计持有期、收益目标、可承受回撤和流动性需求。

## 安全说明

仓库只包含脱敏模板和虚构示例。不要上传客户姓名、账号、真实持仓截图或生成的客户报告。本 Skill 仅形成分析材料，不执行交易，也不替代适当性评估。
